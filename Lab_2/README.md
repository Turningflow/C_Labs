# Лабораторная работа №2 (Вариант 5)
Реализация алгоритмов работы со строками, массивами и матрицами.

## Выполненные задания:
* **T1** — Сумма элементов массива с нечетными значениями.
* **T2** — Максимальные элементы в нечетных столбцах матрицы.
* **T3** — Подсчет слов, начинающихся с согласной буквы.
* **T4** — Взаимная замена слов L1 и L2 в тексте (посимвольный разбор).
